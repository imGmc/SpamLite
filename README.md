# SpamLite

Typecho 垃圾评论拦截插件。基于 SmartSpam 简化重构，专注核心过滤能力。

## 版本

0.1.2

## 兼容性

- Typecho 1.2.1 / 1.3.0
- PHP 8.0 / 8.1 / 8.2 / 8.3

## 功能

- **敏感词汇过滤** — 评论内容、昵称、网址、邮箱分别配置敏感词库
- **非中文评论拦截** — 过滤纯外文垃圾评论
- **并行规则** — 多个过滤规则独立生效，互不阻塞
- **审计日志** — 自动记录每次拦截/标记，保留最近 200 条
- **三种处置方式** — 无动作 / 标记待审核 / 直接拦截

## 安装

1. 将 `SpamLite` 目录上传至 `usr/plugins/`
2. 登录后台 → 控制台 → 插件 → 启用 SpamLite
3. 进入插件设置，配置敏感词和处置策略

## 配置项

| 配置 | 说明 |
|------|------|
| 敏感词汇操作 | 评论内容触犯敏感词时的处理方式 |
| 敏感词汇 | 每行一个敏感词，匹配评论正文 |
| 非中文评论操作 | 评论不含中文时的处理方式 |
| 敏感昵称/网址/邮箱操作 | 对应字段触犯敏感词时的处理方式 |
| 审计日志 | 开启后每次过滤操作写入日志文件 |

## 日志

日志文件位于 `usr/plugins/SpamLite/logs/log`，JSON Lines 格式，自动保留最近 200 条。

> ⚠ 日志文件包含评论者的 IP、邮箱等数据。插件启动时会自动在 `logs/` 目录生成 `.htaccess` 和 `index.html` 防护文件，阻止 Web 直接访问。Nginx 等非 Apache 环境请自行配置访问限制。

查看方式：
- 插件配置页底部实时显示最近 20 条
- 配置页点击"清空日志"一键清空（带 CSRF 保护）

## 变更记录

### 0.1.2

- 新增日志目录 Web 访问防护（`.htaccess` + `index.html`）
- 修复 `log()` 方法并发写入的竞态条件（改用 `flock` 保护完整读写周期）
- 提升 JSON 编码健壮性，畸形 UTF-8 不再污染日志文件
- 重构 `config()` 过滤模板，抽取日志渲染为独立方法
- 抽取 `filter()` 检查器调度为 `checkRule()` 方法
- 消除 `$messages` 数组重复分配，提取为类常量
- `RULES` 配置常量移至类顶部，符合 PHP 约定

### 0.1.1

- 新增 clear_log CSRF 令牌保护
- 修复 `mb_substr` 未指定编码导致中文截断异常的问题
- 修复 `check_in` 收到 null 时触发 PHP Deprecated 的问题
- 消除过滤规则代码重复，抽取为配置数组 + 循环
- 抽取 magic number 为类常量
- 移除赘余的 `@` 错误抑制，替换为显式检查和错误日志
- 清空日志后 URL 净化，移除令牌参数
